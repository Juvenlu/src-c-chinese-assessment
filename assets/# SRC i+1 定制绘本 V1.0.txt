# SRC i+1 定制绘本 V1.0

## 标准冻结 + Audit Engine + Generation上线实施指令

你现在进入 SRC i+1 定制绘本的 **V1.0 上线阶段**。

本阶段核心原则：

> **尽快上线，提前冻结；统计必须严谨，生成允许迭代，人工负责把关。**

不要继续进行大规模理论重构，不要等待更多真实儿童样本才上线。

---

# 一、V1.0正式冻结标准

以下标准从现在开始作为 **SRC i+1 定制绘本 V1.0 Production Standard**。

注意：

> 这些数字是当前版本的生产控制标准，不代表最终教育学标准。未来根据真实儿童阅读数据升级为 V1.1、V1.2 等。

## 1. 篇幅标准

统一使用：

> **中文字符数 = 汉字数量，不含标点。**

### V1.0

| SRC等级  |        目标篇幅 |        允许范围 | 超范围          |
| ------ | ----------: | ----------: | ------------ |
| SRC100 |     150–220 |     150–240 | Warning      |
| SRC300 | **300–350** | **300–380** | >380 Warning |
| SRC500 |     400–500 |     380–540 | Warning      |
| SRC800 |     550–700 |     520–750 | Warning      |

其中：

> **SRC300 的核心目标必须是 300–350 字。**

不要把 300–380 当作新的目标区间。

它只是技术允许区间。

### 篇幅原则

* 不允许为了达到最低字数机械增加句子。
* 不允许为了达到上限机械删除故事内容。
* 故事完整性优先。
* Master Story 不得因为篇幅控制而改变。
* AI Generation阶段应尽量直接生成目标篇幅，而不是生成超长文本后再压缩。

---

# 二、i+1语言负荷标准

## 2.1 外字率

定义：

> 外字出现次数 ÷ 全部中文字符数

V1.0：

> **≤12%**

状态：

* ≤12%：PASS
* > 12%：WARNING
* > 15%：STRONG WARNING / Human Review

必须使用 Occurrence Rate。

不要使用 Unique External Character Rate 作为主要判定指标。

---

# 三、I+1A标准

I+1A定义：

> 当前SRC字符库中的字符可以理解，但组成了当前SRC词汇库之外的自然中文词/语言单位。

V1.0：

> **I+1A Occurrence Rate：20–30%**

状态：

* 20–30%：TARGET
* <20%：LOW
* > 30%：HIGH

注意：

> I+1A 是目标区间，不是最低通过线。

不要为了达到20%机械增加I+1A。

自然故事优先。

---

# 四、High-load标准

High-load：

> 一个自然Language Unit中包含 ≥2 个当前SRC之外的字符。

V1.0：

> **High-load Occurrence Rate ≤12%**

状态：

* ≤12%：PASS
* > 12%：WARNING

> > 12% 不自动判定整本书失败，必须进入人工复核。

故事核心词可以保留。

不得为了降低High-load而改变Master Story。

---

# 五、单页最高负荷

V1.0：

> **单页最高语言负荷 ≤20%**

Page Load用于发现局部阅读难点。

要求：

* 每页独立计算
* 找出最高负荷页
* 记录 page number
* 记录具体负荷指标
* > 20% → WARNING / Human Review

不要只计算全书平均值。

---

# 六、+1重复标准

核心 +1：

> **原则上至少自然出现2次。**

V1.0：

| 次数 | 状态          |
| -: | ----------- |
|  1 | ACCEPTABLE  |
|  2 | RECOMMENDED |
|  3 | GOOD        |
| 4+ | 检查是否机械重复    |

注意：

> 不是所有+1都必须重复。

如果重复会破坏自然叙事，可以出现一次。

不得为了满足Audit机械重复词语。

---

# 七、Language Unit标准继续沿用

不要修改已经确定的Language Unit核心定义。

正式定义：

> Language Unit = 可作为整体理解和学习的自然中文词或固定词汇单位，最少2个汉字。

继续使用：

* candidate construction
* eligibility filter
* longest match
* no overlap / no nesting

继续支持：

* 普通词
* reduplication
* suffix derivation
* 三字自然词
* proper name
* idiom/fixed phrase
* complement structure
* fixed collocation
* SRC vocabulary

继续排除：

* 单字
* pseudo-word
* 临时自由短语
* 完整句子
* 纯句型
* 跨标点字符串
* 整体数量+名词短语
* 整体“得+补语”

不要因为本阶段上线而重新设计Language Unit体系。

---

# 八、Master Story / Master Image必须继续锁定

V1.0严禁修改：

* Master Story
* Master Text
* Master Image
* page sequence
* core event
* character relationship
* ending

AI只能进行：

> **Language Adaptation**

不能进行：

> Story Generation

如果某个i+1无法自然进入故事：

> 放弃该+1，不改变故事。

---

# 九、Generation Engine V1.0

AI Generation目标：

> **I作为基础 → 尽可能自然增加高质量I+1A → 必要时使用I+1B → 严格控制High-load。**

优先级：

1. 已知字 → 新词
2. 高频实用词
3. 故事相关词
4. 常见搭配
5. 常见句式
6. 单个新字

禁止为了提高+1比例而大量增加陌生单字。

# 十一、Child Profile使用规则

继续支持：

* known_characters
* known_vocabulary

* weak_word_signals
* child_nickname
* generation_mode

# 十二、个性化原则

个性化不是：

> 两个孩子必须生成完全不同的文章。

正确原则：

> **只有当儿童数据能够自然影响语言选择时，才产生个性化差异。**

例如：

Child A认识：

> 跳、跑

可以自然使用：

> 跳出来、跳一跳、跑一跑

Child B对这些字符存在Weakness Signal：

可以自然降低这些表达的使用。

但是：

> 不得为了制造差异而强行改写。

如果两个孩子的Profile对当前故事没有产生自然影响：

> 生成相同文本完全允许。
