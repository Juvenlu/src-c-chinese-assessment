# SRC“直接测试”功能二次升级开发提示词

## 一、开发任务

当前平台已经完成“直接测试 / 免费体验测试”第一版。

当前版本存在以下问题：

目前测试结构大致为：

* 单字识别：20题
* 词语识别：10题
* 测试完成后直接生成一个SRC等级

例如：

单字识别：

70%

答对14 / 20字

词语识别：

60%

答对6 / 10词

但系统却可能输出：

SRC800

高级阅读基础

这说明当前评估算法过于简单，存在“单字表现对最终SRC等级影响过大”的问题。

现在请对现有“直接测试”功能进行二次升级。

## 本次升级的核心目标

将原来的：

20个单字 + 10个词语

升级为：

# 最多30个单字 + 最多15个词语

但不要简单增加题量。

必须同时升级：

1. 测试题目分层机制
2. 单字与词语独立评估机制
3. SRC逐级判断机制
4. 自适应测试机制
5. 阅读等级上限机制
6. SRC区间结果机制
7. 置信度机制
8. i+1阅读推荐机制
9. 测试结果页面
10. 后台数据记录

请尽量复用现有SRC字库、现有测试组件、现有注册/登录系统和现有页面，不要重新创建第二套SRC等级体系。

---

# 二、产品定位必须保持不变

“直接测试”是：

# 面向陌生访客的免费中文基础体验测试

不是正式完整测评。

目标：

通过约3–5分钟的轻量测试，初步判断孩子：

1. 单字识别基础
2. 词语识别基础
3. 大致SRC中文阅读字词基础
4. 适合从哪个SRC难度开始阅读
5. 下一步适合什么程度的i+1中文绘本

因此：

# 不追求精确到某一个具体数字

而追求：

# “推荐阅读难度足够准确”

---

# 三、测试最大容量

新的测试容量：

## 单字

最多30题

## 词语

最多15题

合计：

# 最多45题

但是：

# 不要求所有孩子必须完成45题。

必须支持“自适应提前结束”。

---

# 四、SRC测试必须采用分层结构

不要把SRC100、300、500、800、1200全部随机混在一起。

测试必须按照SRC等级形成梯度。

五个主要测试层级：

* SRC100
* SRC300
* SRC500
* SRC800
* SRC1200

---

# 五、单字测试结构

最多30题。

建议每个SRC等级：

6题

即：

| SRC层级   | 单字题数 |
| ------- | ---: |
| SRC100  |    6 |
| SRC300  |    6 |
| SRC500  |    6 |
| SRC800  |    6 |
| SRC1200 |    6 |
| 总计      |   30 |

但是：

# 后台必须允许未来调整每个等级的题数。

不要把6题硬编码到前端。

建议配置：

character_questions_per_level = 6

---

# 六、词语测试结构

最多15题。

每个SRC等级：

3题。

| SRC层级   | 词语题数 |
| ------- | ---: |
| SRC100  |    3 |
| SRC300  |    3 |
| SRC500  |    3 |
| SRC800  |    3 |
| SRC1200 |    3 |
| 总计      |   15 |

后台配置：

word_questions_per_level = 3

---

# 七、题目选择原则

虽然按照SRC等级分层，但同一等级内部仍然必须随机抽题。

不能所有用户永远看到相同的6个单字或3个词语。

每次测试：

从对应SRC等级题库中随机抽取。

但必须避免：

1. 同一次测试重复
2. 同一用户短时间内重复率过高
3. 同一字符同时出现在不合理的多个题目中

---

# 八、必须保证SRC字库层级的严格性

如果题目标记为：

SRC300

则该题应该来自SRC300对应字词库。

不要出现：

题目标签SRC300，但实际字符属于SRC800或1200。

后台应检查：

question.src_level

与实际SRC字库等级是否一致。

---

# 九、测试不是简单一次性完成45题

必须采用：

# “逐级测试 + 自适应终止”

逻辑如下：

SRC100
↓
判断是否达到通过标准
↓
如果通过 → SRC300
如果未通过 → 停止或定位在SRC100附近
↓
SRC300
↓
如果通过 → SRC500
如果未通过 → 停止
↓
SRC500
↓
如果通过 → SRC800
如果未通过 → 停止
↓
SRC800
↓
如果通过 → SRC1200
如果未通过 → 停止
↓
SRC1200

---

# 十、但不要要求100%正确才能进入下一级

建议默认阈值：

## 单字

SRC100：

≥80% → 可以进入SRC300

SRC300：

≥80% → 可以进入SRC500

SRC500：

≥75% → 可以进入SRC800

SRC800：

≥75% → 可以进入SRC1200

SRC1200：

用于挑战和确定上限，不要求继续升级。

所有阈值必须后台可调整。

例如：

character_pass_threshold_100 = 0.80
character_pass_threshold_300 = 0.80
character_pass_threshold_500 = 0.75
character_pass_threshold_800 = 0.75

不要硬编码。

---

# 十一、词语测试必须独立形成一条能力阶梯

词语不能因为单字通过就自动视为通过。

必须单独计算：

SRC100词语正确率
SRC300词语正确率
SRC500词语正确率
SRC800词语正确率
SRC1200词语正确率

词语也按照自己的阈值判断。

建议默认：

SRC100：≥80%
SRC300：≥80%
SRC500：≥75%
SRC800：≥75%
SRC1200：挑战

所有阈值可后台调整。

---

# 十二、单字与词语绝对不能简单平均

禁止使用这种算法：

(character_score + word_score) / 2

然后直接对应SRC等级。

例如：

单字：

80%

词语：

60%

不能计算成：

70%

然后直接判断SRC800。

---

# 十三、建立“能力水位”

测试结束后，分别计算：

## character_level

孩子稳定单字识别达到的最高SRC等级。

## word_level

孩子稳定词语识别达到的最高SRC等级。

例如：

character_level = SRC800

word_level = SRC500

这是允许的。

因为孩子可能：

“认识很多孤立汉字，但词语识别和阅读基础还没有同步发展。”

---

# 十四、增加“阅读等级天花板”

这是本次升级最重要的规则之一。

最终推荐阅读等级不能简单使用character_level。

必须受到word_level约束。

建议：

# reading_base_level = min(character_level, word_level)

例如：

单字：

SRC800

词语：

SRC500

那么：

reading_base_level = SRC500

不能输出SRC800阅读基础。

---

# 十五、建议增加第三维：简单语境测试

如果当前系统开发成本允许，建议增加5个非常简单的语境题。

例如：

“孙悟空拿着一根______。”

A 金箍棒
B 书包
C 铅笔

目的不是考文学知识。

而是判断：

# 孩子能否在简单上下文中理解已经认识的词语。

如果暂时不增加语境测试，则不要在结果页面声称：

“完整阅读理解能力”。

只允许使用：

“中文阅读字词基础”。

---

# 十六、如果暂时没有语境测试

最终推荐阅读等级：

reading_base_level = min(character_level, word_level)

然后加入轻度i+1。

例如：

reading_base_level = SRC500

推荐：

SRC500–550

而不是直接：

SRC800。

---

# 十七、i+1推荐算法

最终测试必须产生：

recommended_reading_level

例如：

如果：

reading_base_level = SRC100

推荐：

SRC110–150

如果：

reading_base_level = SRC300

推荐：

SRC320–350

如果：

reading_base_level = SRC500

推荐：

SRC520–550

如果：

reading_base_level = SRC800

推荐：

SRC820–880

如果：

reading_base_level = SRC1200

推荐：

SRC1200附近的轻度挑战内容。

注意：

# 不允许简单理解为“下一个SRC等级”。

例如：

SRC500不能直接推荐SRC800绘本。

必须采用连续的小幅i+1。

---

# 十八、结果必须使用“区间”，不要过度精确

不要只显示：

SRC800

应该显示：

# 预计中文阅读字词基础：SRC500左右

或者：

# 初步范围：SRC300–500

根据测试稳定程度决定区间宽度。

---

# 十九、增加“置信度”

新增：

confidence

三个等级：

* 高
* 中
* 低

例如：

### 高

测试覆盖充分，而且相邻等级结果稳定。

### 中

测试结果基本稳定，但题量有限或相邻等级存在波动。

### 低

测试题量不足、结果波动较大，或者单字与词语能力差异较大。

---

# 二十、特别处理“单字与词语差距很大”的情况

例如：

单字：

SRC800

词语：

SRC300

不要直接给：

SRC300

然后结束。

应该在结果中提示：

# “孩子的单字识别能力明显高于词语识别能力。”

并推荐：

# “以词语阅读和短篇趣味阅读为重点进行巩固。”

这对于老师和家长非常有价值。

# 三十六、最重要的开发原则

请严格遵守以下原则：

> **第一：30个单字和15个词语是最大测试容量，不是所有孩子必须完成的固定题量。**

> **第二：单字和词语必须分开测量、分开计算。**

> **第三：单字能力不能掩盖词语能力不足。**

> **第四：词语能力不足时，最终阅读等级必须受到限制。**

> **第五：不要用简单平均分直接映射SRC等级。**

> **第六：最终结果应该优先服务于“推荐什么难度的书”，而不是追求一个看起来非常精确的SRC数字。**

> **第七：游客测试结果只能称为“初步估测”，不能等同于正式SRC测评。**

> **第八：所有参数后台可调整。**

> **第九：所有测试历史必须保留，不能覆盖旧结果。**

> **第十：测试结果最终必须能够无缝连接到后续i+1绘本推荐系统。**
