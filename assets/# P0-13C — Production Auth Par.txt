- home_language TEXT
- home_language_other TEXT

- id INTEGER PRIMARY KEY AUTOINCREMENT
- email TEXT NOT NULL
- code_hash TEXT NOT NULL
- purpose TEXT NOT NULL
- expires_at TEXT NOT NULL
- attempts_remaining INTEGER DEFAULT 5
- used INTEGER DEFAULT 0
- revoked INTEGER DEFAULT 0
- created_at TEXT

现有旧代码使用：

parents_profiles

而 D1 正式表为：

parents

这是已知 mapping difference。

现有旧代码中的部分 ID 为 UUID。

D1 使用：

INTEGER AUTOINCREMENT

因此：

**不能直接复制旧 UUID 到 D1。**

必须由 D1 生成新的 INTEGER ID。

==================================================
五、现有 Session 的重要安全问题
==================================================

P0-13B 已确认当前 session token：

- 不是 JWT
- 没有签名
- 没有 expiry
- 本质上是 Base64(JSON)
- payload 包括 uid / email / iat
- 可以被伪造

因此：

**绝对不能把当前 unsigned Base64 session 原样作为未来正式生产家长测试的长期认证方案。**

P0-13C 必须设计新的安全 session 方案。

优先考虑：

- HMAC signed session
- exp / expiry
- parent_id
- email
- issued_at
- signature

优先考虑 Web Crypto / Worker 原生能力。

Secret 必须：

- 只存在于 Cloudflare Worker Secret
- 不进入 GitHub
- 不进入代码
- 不进入 wrangler.toml
- 不进入日志
- 不进入 Agent 输出

本阶段只做设计，不创建 Secret。
