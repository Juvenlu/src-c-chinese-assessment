# SRC Primary Database

## D1 Schema V2.1 Final Blueprint

**状态：FINAL / Schema Freeze**

核心原则：

> **SRC Primary Database = SRC 平台唯一业务数据源（Single Source of Truth）。**

V1.0 不新增未来预留业务表，不保存可由原始事实实时计算得到的重复数据。

# A. Final D1 Schema V2.1

## 1. parents

```sql
CREATE TABLE parents (
  id TEXT PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  email_verified INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'active',
  created_at INTEGER NOT NULL,
  updated_at INTEGER,
  CHECK (status IN ('active', 'suspended', 'deleted'))
);

CREATE INDEX idx_parents_email ON parents(email);
CREATE INDEX idx_parents_status ON parents(status);
```

**Purpose：** 家长身份凭证与账户核心信息。

## 2. children

```sql
CREATE TABLE children (
  id TEXT PRIMARY KEY,
  parent_id TEXT NOT NULL,
  nickname TEXT NOT NULL,
  age INTEGER NOT NULL,
  grade TEXT NOT NULL,
  country TEXT NOT NULL,
  home_language TEXT,
  home_language_other TEXT,
  status TEXT NOT NULL DEFAULT 'active',

  estimated_level TEXT,
  confirmed_level TEXT,
  assessment_status TEXT NOT NULL DEFAULT 'not_started',

  created_at INTEGER NOT NULL,
  updated_at INTEGER,

  FOREIGN KEY (parent_id) REFERENCES parents(id) ON DELETE CASCADE,

  CHECK (
    assessment_status IN (
      'not_started',
      'quick_done',
      'formal_in_progress',
      'formal_done'
    )
  ),

  CHECK (
    estimated_level IS NULL OR
    estimated_level IN ('SRC100', 'SRC300', 'SRC500', 'SRC800')
  ),

  CHECK (
    confirmed_level IS NULL OR
    confirmed_level IN ('SRC100', 'SRC300', 'SRC500', 'SRC800')
  )
);

CREATE INDEX idx_children_parent_id ON children(parent_id);
CREATE INDEX idx_children_confirmed_level ON children(confirmed_level);
CREATE INDEX idx_children_status ON children(status);
```

**核心规则：**

* `estimated_level` = Quick Assessment 结果
* `confirmed_level` = Formal Level Decision Algorithm 的当前正式等级
* `confirmed_level` 是系统当前正式阅读等级的唯一权威值
* 前端、Growth Map、Book Generator 不得自行决定等级

## 4. test_sessions

```sql
CREATE TABLE test_sessions (
  id TEXT PRIMARY KEY,
  child_id TEXT NOT NULL,
  level TEXT,
  test_type TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'in_progress',

  started_at INTEGER NOT NULL,
  completed_at INTEGER,
  time_limit_seconds INTEGER,
  total_questions INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,

  CHECK (
    (test_type = 'quick') OR
    (
      test_type IN ('sampling', 'formal')

  ),

  CHECK (status IN ('in_progress', 'completed', 'abandoned'))

CREATE INDEX idx_sessions_child_id ON test_sessions(child_id);
CREATE INDEX idx_sessions_type ON test_sessions(test_type);
CREATE INDEX idx_sessions_status ON test_sessions(status);
CREATE INDEX idx_sessions_child_status
  ON test_sessions(child_id, test_type, status);
```

**规则：**

* Quick：`level` 可以 NULL
* Sampling/Formal：必须有 SRC 等级

## 6. test_results

```sql
CREATE TABLE test_results (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL UNIQUE,
  child_id TEXT NOT NULL,

  level TEXT NOT NULL,
  test_type TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'completed',

  character_score INTEGER NOT NULL,
  vocab_score INTEGER NOT NULL,
  reading_score INTEGER NOT NULL,
  comprehension_score INTEGER NOT NULL,
  total_score INTEGER NOT NULL,

  stable_char_count INTEGER NOT NULL,
  stable_vocab_count INTEGER NOT NULL,

  completion_time_seconds INTEGER NOT NULL,
  total_questions INTEGER NOT NULL,
  correct_count INTEGER NOT NULL,

  known_characters_json TEXT,
  weak_characters_json TEXT,
  part_breakdown_json TEXT,

  completed_at INTEGER NOT NULL,
  created_at INTEGER NOT NULL,

  FOREIGN KEY (session_id)
    REFERENCES test_sessions(id) ON DELETE CASCADE,

  FOREIGN KEY (child_id)
    REFERENCES children(id) ON DELETE CASCADE,

  CHECK (test_type IN ('sampling', 'formal')),

  CHECK (status IN ('completed', 'invalid')),

  CHECK (
    level IN ('SRC100', 'SRC300', 'SRC500', 'SRC800')
  )
);

CREATE INDEX idx_results_child_id
  ON test_results(child_id);

CREATE INDEX idx_results_level
  ON test_results(level);

CREATE INDEX idx_results_child_type
  ON test_results(child_id, test_type, status);

CREATE INDEX idx_results_completed_at
  ON test_results(completed_at DESC);
```

### P0 核心规则

> **`test_results` = 每一次已完成测试的历史结果。**

同一个孩子可以有：

```text
Formal SRC300
Formal SRC500
Formal SRC300（复测）
Formal SRC800
```

每次都新增一条记录，**不得覆盖历史**。

### 当前正式测试结果

```sql
WHERE test_type = 'formal'
  AND status = 'completed'
ORDER BY completed_at DESC
LIMIT 1
```

即：

> **当前测试结果 = 最新一次有效完成结果。**

不得：

* 取最高等级
* 取 MAX(level)
* 用最高等级测试作为当前结果
* 用历史最高 stable_char_count 代替当前结果

### confirmed_level

必须通过：

```text
test_answers
      ↓
test_results
      ↓
Formal Level Decision Algorithm
      ↓
children.confirmed_level
```

而不是：

```text
MAX(formal_test.level)
```

## 7. quick_assessment_results

```sql
CREATE TABLE quick_assessment_results (
  id TEXT PRIMARY KEY,
  session_id TEXT UNIQUE,
  child_id TEXT,

  recommended_level TEXT NOT NULL,

  total_questions INTEGER NOT NULL DEFAULT 0,
  correct_count INTEGER NOT NULL DEFAULT 0,

  raw_result_json TEXT,

  completed_at INTEGER NOT NULL,
  created_at INTEGER NOT NULL,

  FOREIGN KEY (session_id)
    REFERENCES test_sessions(id) ON DELETE SET NULL,

  FOREIGN KEY (child_id)
    REFERENCES children(id) ON DELETE SET NULL,

  CHECK (confidence IN ('high', 'medium', 'low')),

  CHECK (
    recommended_level IN ('SRC100', 'SRC300', 'SRC500', 'SRC800')
  )
);

CREATE INDEX idx_quick_child_id
  ON quick_assessment_results(child_id);

CREATE INDEX idx_quick_confidence
  ON quick_assessment_results(confidence);
```

### estimated_level 唯一来源

```text
Quick Assessment
      ↓
quick_assessment_results.recommended_level
      ↓
children.estimated_level
```

Formal Test：

> **不得覆盖 `estimated_level`。**

因此：

```text
estimated_level = SRC500
confirmed_level = SRC300
```

在系统中完全允许。

# B. Relationship Map

```text
parents
   │
   ├─── (1) subscriptions
   │
   ├─── (1) book_entitlements
   │
   └─── (N) children
            │
            ├─── (N) test_sessions
            │          │
            │          ├─── (N) test_answers
            │          │
            │          ├─── (1) test_results
            │          │
            │          └─── (1) quick_assessment_results
            │
            ├─── (N) custom_books
            │          │
            │          └─── (1) book_rewrite_versions
            │                       │
            │                       └─── (1) book_episodes
            │                                  │
            │                                  └─── (N) book_episode_pages
            │
            └─── (N) reading_records
                       │
                       └─── custom_books

        │
```

关键关系：

```text

children → custom_books

```

# C. Source of Truth Map

| 核心数据                 | 唯一 Source of Truth                                                        | 更新/计算方式                            |
| -------------------- | ------------------------------------------------------------------------- | ---------------------------------- |
| Quick 答题事实           | `test_sessions` + `test_answers`                                          | 每答一题写入                             |
| Quick 结果             | `quick_assessment_results`                                                | Quick 完成时写入                        |
| `estimated_level`    | `quick_assessment_results.recommended_level` → `children.estimated_level` | Quick 完成时                          |
| Formal 答题事实          | `test_sessions` + `test_answers`                                          | 每答一题写入                             |
| 历次正式测试结果             | `test_results`                                                            | 每次完成新增，不覆盖                         |
| **当前正式测试结果**         | `test_results`                                                            | 最新有效完成结果                           |
| `confirmed_level`    | `children.confirmed_level`                                                | Formal Level Decision Algorithm 更新 |
| `stable_char_count`  | 最新有效 `test_results`                                                       | 实时查询                               |
| `stable_vocab_count` | 最新有效 `test_results`                                                       | 实时查询                               |
| Character Mastery    | `test_answers`                                                            | 实时计算                               |
| Vocabulary Mastery   | `test_answers`                                                            | 实时计算                               |
| 阅读行为事实               | `reading_records`                                                         | 每次阅读写入                             |
| 阅读次数/时长/最近阅读         | `reading_records`                                                         | 实时聚合                               |
| 孩子书架                 | `custom_books`                                                            | Final rewrite 分配后创建                |
| i+1 改写内容             | `book_rewrite_versions`                                                   | 每次生成新增版本                           |
| Master Story         | `book_episodes` + `book_episode_pages`                                    | Master Asset Lock                  |
| 免费绘本额度               | `book_entitlements`                                                       | 注册初始化/使用时更新                        |
| Subscription         | `subscriptions`                                                           | 订阅状态变化时更新                          |
| Growth Map           | 多个核心事实实时计算                                                                | 不持久化                               |

## 最核心的数据链

### estimated_level

```text
Quick Assessment
      ↓
quick_assessment_results
      ↓
children.estimated_level
```

### confirmed_level

```text
Formal Test
      ↓
test_answers
      ↓
test_results
      ↓
Formal Level Decision Algorithm
      ↓
children.confirmed_level
```

### i+1 定制绘本

```text
children.confirmed_level
        +
test_answers / Reading Profile
        +
Master Story
        ↓
Book Generator
        ↓
book_rewrite_versions
        ↓
Final Version
        ↓
custom_books
```

### 阅读成长

```text
reading_records
      +
test_results
      +
test_answers
      +
children.confirmed_level
      +
custom_books
      ↓
Growth Map
```

# D. Preliminary PostgreSQL → D1 Migration Map

> **本表仅为 Preliminary Migration Map。**
>
> 在实际迁移前，必须先对旧 PostgreSQL 做完整 schema introspection。不得把当前推测字段视为已确认事实。

| PostgreSQL                 | D1                                           | 当前已知映射                                                  | 必须验证                                                 |
| -------------------------- | -------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| `parents_profiles`         | `parents`                                    | id、email、password_hash、email_verified、status、created_at | 实际字段名、类型；subscription 字段；last_login_at               |
| `parents_profiles`         | `subscriptions`                              | 如存在 subscription 信息，可转换初始化                              | 实际 subscription_status、plan_type、subscription_id     |
| —                          | `book_entitlements`                          | 每个 parent 初始化 10；used 可由实际书架数据计算                        | 旧数据中的实际可用书/历史赠送规则                                    |
| `children`                 | `children`                                   | 基础身份字段直接映射                                              | parent_id 类型；等级字段实际来源                                |
| `question_bank`            | `question_bank`                              | 基本题库字段映射                                                | difficulty、JSON 字段实际类型                               |
| `test_sessions`            | `test_sessions`                              | child_id、level、时间、status 等                              | test_mode 实际枚举；total_questions 是否存在                  |
| `test_answers`             | `test_answers`                               | 答题事实基本映射                                                | question_content、is_recognized 等字段                   |
| `test_results`             | `test_results`                               | 得分、stable counts、known chars 等映射                        | test_mode、total_questions、correct_count、completed_at |
| `quick_assessment_results` | `quick_assessment_results`                   | 等级边界、reading_base、confidence、raw_result 等               | recommended_level、session_id、完成时间等                   |

# E. Remaining Risks

## 1. Formal Level Decision Algorithm 尚未最终定义

Schema 已经确定：

```text
正式测试历史
    ↓
Formal Level Decision Algorithm
    ↓
confirmed_level
```

但算法本身仍需要定义：

* 等级确认阈值
* 稳定区间
* 复测规则
* 测试异常处理
* 等级退化处理

这是应用层规则，不阻塞 Schema Freeze。

---

## 2. 旧 PostgreSQL Schema 尚未实际 introspect

当前 Migration Map 只能作为：

> **Preliminary**

不得依据推测字段直接执行迁移。

下一阶段首先应该：

> **Read-only introspection → 生成 Final Migration Map**

---

## 3. 历史阅读数据可能不完整

旧系统如果只有：

```text
custom_books.times_read
```

而没有逐次：

```text
reading_records
```

则不能还原历史阅读时长、页面阅读轨迹等。

处理原则：

> 能准确迁移的迁移；无法准确还原的不要伪造。

从 D1 正式启用后开始积累完整 `reading_records`。

---

## 4. Character/Vocabulary Mastery 的实时计算性能

V1.0 数据量较小时：

> 直接从 `test_answers` 聚合即可。

未来数据量明显增长后，如有必要再增加缓存或异步计算。

**当前不增加 mastery snapshot 表。**

---

## 5. Growth Map 查询性能

Growth Map 需要组合：

```text
children
+
latest test_results
+
test_answers aggregation
+
reading_records aggregation
+
custom_books
```

V1.0 先实际测试：

> Vercel → Worker → D1

的真实响应时间。

只有实际出现性能问题，才考虑缓存。

---

## 6. OTP 限流

V1.0：

> 密码登录为主，OTP 为可选。

因此不恢复：

```text
otp_rate_limit
```

如未来启用 OTP 限流，优先考虑 Worker/KV 等应用层能力。
