# SRC 工程标准文件包 V1.0

这是可交给扣子 Agent 纳入 SRC GitHub 仓库的**建议标准文件包**，并非已写入用户仓库或扣子工作区。请先执行只读对照，确认已有 AGENTS.md、docs/standards 等文件，不得覆盖。建议将本包 `standards/` 内容置于仓库根目录 `standards/`，`AGENTS.md` 放仓库根目录；若已有文件，先差异合并并经管理员审核。

第一阶段：只读核验现有规则、代码和文件结构；提交拟合并清单与冲突报告。
第二阶段：管理员单独授权后创建/合并标准文件、提交 PR；不自动部署。
第三阶段：在扣子 Agent 的持久项目说明中写明“每次任务先读取仓库 AGENTS.md 与相关标准”；用新会话实测能否自动读取，并要求每次报告列出规则文件版本。不能保证扣子产品在未配置时自动加载这些文件。

重要：M01-M11 多数为初始基线，须经逐模块代码和 Production 只读证据校准。不得把文档设计当成当前代码事实。
